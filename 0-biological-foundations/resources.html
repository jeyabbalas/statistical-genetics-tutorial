How to use this page

The thirteen topic sections follow the order of the lecture pages, and each one starts with a link back to its page. The sections after them group resources by type: books, key review papers, databases, software, UK Biobank’s own resources, and videos. Within each list, resources run from introductory to advanced, so the first item is a good place to start.
