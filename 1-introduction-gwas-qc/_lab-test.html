The R console

The first run downloads R (WebR) into the browser; later runs reuse it. The code reads the same files as the terminals.

plink --bfile ${input_dir}/toy --missing --out ${analysis_dir}/toy
library(data.table)
library(ggplot2)
variant_miss <- fread(file.path(analysis_dir, "toy.lmiss"))
print(head(variant_miss))
ggplot(variant_miss, aes(x = F_MISS)) +
  geom_histogram(bins = 50) +
  geom_vline(xintercept = 0.01, color = "red") +
  labs(title = "Variant missingness (toy data)")
